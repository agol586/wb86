# MacWubi v1.4

## 主要更新

- 新增默认关闭的“显示扩展汉字”设置，日常候选按 Rime `charset_filter` 范围隐藏扩展 CJK 与兼容汉字。
- 开启该设置后可恢复当前有界查询窗口中的完整基础五笔、用户词库和本地拼音候选。
- 设置快照升级到 schema v3，既有 v1/v2 设置按原子迁移链保留原有语义，新选项使用兼容默认值。
- 补齐扩展 A…J、兼容区边界、`wqvb` 默认候选、设置回显、持久化和迁移回归测试。
- 用户指南、验证记录、Spec Kit 规格、计划、数据模型与契约已同步到实际实现。

## 验证

- 完整产品 XCTest：264 项通过，0 失败。
- 发布契约 XCTest：9 项通过，0 失败。
- 确定性词库编译与 fixture 验证通过。
- 全功能查询基准 9 类样本、每类 20 次热身与 100 次测量；最大值 1.5545 ms，全部 `< 2 ms`。
- Apple Development 签名 Release 构建通过，包内版本为 1.4 (11)，原生 arm64。
- Hardened Runtime、依赖、离线能力、许可证和隐私发布契约验证通过。

> 本 Release 提供源码归档。当前环境没有 Developer ID Application 身份，因此未提供公证安装包；
> 正式分发安装包仍须完成 Developer ID 签名、公证、staple、Gatekeeper 与完整硬件矩阵门禁。
