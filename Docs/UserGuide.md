# Mac Wubi 86 用户指南

## 支持范围

Mac Wubi 86 仅支持 Apple Silicon（`arm64`）Mac，最低系统为 macOS 13。Intel Mac、
`x86_64`、Rosetta 2、Mac App Store 和 App Sandbox 均不在支持范围。输入、词库、学习和设置
完全在本机完成，产品不建立网络连接。

VoiceOver、旁白实用工具、Accessibility Inspector，以及屏幕阅读器专用的候选朗读、辅助
焦点、辅助选择和设置导航明确不受支持。系统开启这些工具时，输入法仍应保持一般故障安全，
但不保证其语音或辅助导航行为。普通鼠标/键盘操作、深浅色、高对比度、减少动态效果、缩放和
多显示器布局仍在支持范围内。

## 安装与启用

1. 使用可信的已签名构建，执行 `Scripts/install.sh /绝对路径/MacWubi.app`，并按系统提示提供
   管理员授权。脚本会验证并安装到 `/Library/Input Methods/MacWubi.app`。
2. 打开“系统设置 → 键盘 → 文本输入 → 编辑”，在中文输入源中添加“Mac Wubi 86”。
3. 从菜单栏输入菜单选择“Mac Wubi 86”，在普通文本区域输入 `wqvb`，按空格提交首选。

若输入源没有出现，先确认 bundle 位于系统级目录、签名有效且架构只有 `arm64`，然后注销并
重新登录。不要关闭 Gatekeeper 或 SIP。开发构建与最终 Developer ID 公证构建的验证要求见
[SigningAndDistribution.md](SigningAndDistribution.md)。

## 日常输入

- 五笔编码接受大小写等价的 `a` 到 `y`，长度为一至四码。
- 空格提交首选，数字 `1` 至 `9` 选择对应候选，Escape 取消，Delete/Backspace 修码。
- 默认同时启用 `,`/`.`、`-`/`=`、`[`/`]` 和 Shift-Tab/Tab 前后翻页；上/下方向键可选。
- 候选也可用鼠标或触控板选择。可独立设置四码唯一自动上屏、五码首选上屏，以及用
  分号/单引号选择当前页第二/第三候选。
- 不属于输入法的 Command、Control 或 Option 系统/应用快捷键会安全清除未提交组合后传递。

全新安装默认用单独按下并释放 Shift 切换中英文、Control-Shift-F 切换简繁，全半角快捷键
默认禁用；三者均可在“按键”中改为受支持的预设或禁用。Shift 与字母/其他修饰键组合、长按
或重复事件不会误切换。输入菜单也会显示并切换这些状态。切换模式时未提交组合会被安全取消，
不会把原始编码写入文档。新会话默认中文、简体、半角、英文标点。

默认开启完全本地的五笔拼音混输。连续全拼有效前缀会继续组合；候选先显示五笔、再显示拼音，
按最终显示文本去重并遵循当前简繁模式。可关闭混输恢复纯五笔行为。编码提示默认开启，有已知
五笔编码时显示在候选正文之后；关闭提示不会改变候选顺序或提交结果。产品不联网查询拼音。

## 设置与个性化

设置窗口包含“常用、按键、外观、高级”四组：

- 常用：初始中英文、简繁、全半角、中文模式标点，以及四码唯一、五码首选、自动调频、
  混输、编码提示和候选 2/3 快捷键。
- 按键：中英文/简繁/全半角切换键、五组翻页键和 US/跟随系统键盘布局。
- 外观：每页 5–9 个候选、横/纵布局和 0.8–2.0 字号缩放。
- 高级：私密、学习、用户词库和显式导入导出操作。

“保存”先校验范围、重复/保留快捷键和布局可用性；失败时最后有效设置继续运行并把焦点定位到
对应控件。“取消”丢弃未保存草稿。外观可即时更新，改变输入语义的设置由每个会话在当前组合
安全结束后整体采用，不会中途混用新旧设置。“恢复默认…”要求确认且只重置 Settings，不会
删除用户词库、学习数据或关闭私密模式。

本地学习只改变同码候选顺序，不改变编码和基础词库。用户词条可添加、编辑、搜索、删除、
批量清除，并通过显式打开/保存面板导入导出。文本格式为 UTF-8、每行
`code<TAB>text<TAB>rank`；产品归档格式带版本并原子验证。失败报告只包含计数和类别。

## 私密模式、迁移与恢复

可从输入菜单或“隐私”设置开启私密模式。开启后不写学习数据，既有学习分数也不参与排序。
隐私页只显示 Settings、UserLexicon、Learning 三个域的用途、逻辑位置和字节数，不显示内容。
可单独删除任一域或删除全部个性化数据；只读基础词库始终保留。

兼容升级会逐版本迁移并原子替换快照，最多保留一个已验证的上一版本。损坏只隔离所属域；
未知未来版本会原样保留并停止降级。升级使用 `Scripts/upgrade.sh /绝对路径/MacWubi.app`。

## 卸载

`Scripts/uninstall.sh` 只移除输入法并保留个人数据。仅在明确希望同时删除所有个性化数据时
执行 `Scripts/uninstall.sh --delete-data`。删除后不可通过产品恢复，基础 bundle 可重新安装。
