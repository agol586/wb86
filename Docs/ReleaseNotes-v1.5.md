# MacWubi v1.5

## 主要更新

- 设置窗口现在明确区分已保存状态和未保存草稿；Save/Cancel 仅在有修改时可用，所有持久化控件即时
  更新草稿状态。
- 外观页候选预览复用实际候选的序号、首选形状强调、纵横排列和有界字号层级。
- 候选窗实时响应系统“减少透明度”和“增强对比度”，在需要时切换自适应实色背景并加强边框。
- 官网重构为完整的体验、隐私、安装和 FAQ 路径，支持系统深浅色、移动端、键盘焦点和减少动态效果。
- 高频候选出现、键盘翻页和提交路径保持即时，没有新增动画、依赖、网络能力或遥测。

## 版本与分发边界

- Bundle 版本为 1.5 (12)，仅支持原生 arm64 与 macOS 13+。
- v1.5 以不可变标签和 GitHub 生成的源码归档发布；本地 Apple Development 包仅用于本机升级验证。
- 当前没有 Developer ID Application 身份；未完成公证、staple 与 Gatekeeper 公开分发门禁，不提供或
  声称存在已公证的一键安装包。
