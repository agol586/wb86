# MacWubi v1.5.3

## 修复

- 五笔或有效拼音组合在本地词典没有匹配项时，候选栏会保留原始输入，用户可以继续编辑或选择上屏。
- 原码候选适用于所有无候选长度，不限于四码；输入第五码时会按现有分段设置处理上一段，再开始新的组合。
- 原码候选不会被四码唯一候选规则自动上屏，也不会写入学习记录。

## 版本与分发边界

- Bundle 版本为 1.5.3 (15)，仅支持原生 arm64 与 macOS 13+。
- v1.5.3 以不可变标签和 GitHub 生成的源码归档发布；本地 Apple Development 签名包用于本机升级验证。
- 当前没有 Developer ID Application 身份；未完成公证、staple 与 Gatekeeper 公开分发门禁，不提供或
  声称存在已公证的一键安装包。
