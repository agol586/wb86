# MacWubi v1.5.1

## 修复

- 修复默认开启“五笔拼音混输”时，输入小写 `z` 会直接输出字母且不显示候选窗口的问题。
- 混输关闭时继续把 `z` 作为普通文本处理；中文空闲态的大写字母原样组合规则保持不变。

## 版本与分发边界

- Bundle 版本为 1.5.1 (13)，仅支持原生 arm64 与 macOS 13+。
- v1.5.1 以不可变标签和 GitHub 生成的源码归档发布；本地 Apple Development 包仅用于本机升级验证。
- 当前没有 Developer ID Application 身份；未完成公证、staple 与 Gatekeeper 公开分发门禁，不提供或
  声称存在已公证的一键安装包。
