# MacWubi v1.5.4

## 修复

- 当前输入没有词典候选时，后续字母会继续追加到同一个原码候选；超过四码也不会分段、上屏或清空，
  直到用户按空格、回车或显式选择后整体提交。
- 普通五笔和拼音组合按 Return 或数字键盘 Enter 时提交当前原始编码并关闭候选，不再清空未提交文本。
- 回车由输入法消费，不选择候选、不写入学习记录，也不向应用额外插入换行。
- 修复混合拼音模式下第二个 `z` 被清空的问题；`zz` 现在保留为原码候选，并可用空格或回车提交。
- 修复输入位置靠近屏幕底部时候选框覆盖输入字符的问题；下方空间不足时会改在输入行上方显示，
  并与 marked text 保留间距。

## 版本与分发边界

- Bundle 版本为 1.5.4 (16)，仅支持原生 arm64 与 macOS 13+。
- v1.5.4 以不可变标签和 GitHub 生成的源码归档发布；本地 Apple Development 签名包用于本机升级验证。
- 当前没有 Developer ID Application 身份；未完成公证、staple 与 Gatekeeper 公开分发门禁，不提供或
  声称存在已公证的一键安装包。
