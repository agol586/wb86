# MacWubi v1.5.2

## 修复

- 横排候选的页码移到第一排末尾，仅显示 `1/10` 这样的格式。
- 横排单页也显示 `1/1`，并预留页码宽度；候选内容相同时，单页、多页及页码位数变化不再导致窗口尺寸跳动。
- 竖排候选保留原有分页页脚，候选选择、翻页键和输入行为保持不变。

## 版本与分发边界

- Bundle 版本为 1.5.2 (14)，仅支持原生 arm64 与 macOS 13+。
- v1.5.2 以不可变标签和 GitHub 生成的源码归档发布；本地 Apple Development 签名包用于本机升级验证。
- 当前没有 Developer ID Application 身份；未完成公证、staple 与 Gatekeeper 公开分发门禁，不提供或
  声称存在已公证的一键安装包。
