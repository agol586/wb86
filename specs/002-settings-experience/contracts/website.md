# Contract: 官方网页体验

## 信息与任务路径

- 首屏必须在一次视线内说明产品名称、五笔 86 定位、Apple Silicon/macOS 13+ 边界、完全离线特性和
  当前 v1.5.1 源码 Release 状态；不得把尚未完成的 Developer ID 公证安装包描述为已可直接安装。
- 主导航和页面顺序覆盖“体验 → 隐私 → 安装 → 常见问题”，用户无需离开页面即可判断产品是否适合、
  如何获取、如何启用以及当前发布边界。
- 安装区必须提供 v1.5.1 Release 源码获取、构建、系统设置启用三步，并链接到完整用户指南、签名说明
  和 GitHub issue。
- 性能、内存、隐私和平台支持声明必须与宪章、README 和发布门禁一致。

## 视觉、动效与可访问性

- 使用系统字体、语义 HTML、可见键盘焦点、正文跳转链接和不少于 44pt 的主要触控目标；在 375px、
  768px 和桌面宽度保持可读且不横向溢出。
- 自动跟随系统深浅外观；透明材质只作增强，内容在不支持模糊和开启减少透明度时仍清楚可辨。
- 动画只用于首次解释产品与低频按压反馈，只改变 transform/opacity，单次 UI 反馈不超过 300ms；键盘
  导航与高频输入示意不得被动画阻塞，并完整响应 `prefers-reduced-motion`。
- 悬停视觉变化必须限制在支持精细指针和 hover 的设备；不得使用 `transition: all`、`scale(0)` 或
  `ease-in` UI 曲线。

## 交付

- 官网继续使用仓库内 `website/` 的无构建静态架构和现有 GitHub Pages 工作流，不增加运行时依赖、
  跟踪脚本、外部字体、cookie、账户或网络请求。
- 社交分享图、图标、canonical、Open Graph 和 Twitter 元数据保持完整；页面发布仍由 main 分支的
  `website/**` 变更触发，本地实现不得自动 push 或绕过现有发布流程。
