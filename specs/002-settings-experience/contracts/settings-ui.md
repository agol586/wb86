# Contract: 设置窗口与普通鼠标/键盘操作

## Pages

- 设置窗口使用 `preference` 风格的原生工具栏切换四个面板。工具栏始终可见、不可自定义、显示图标与
  标签并明确选中当前面板；面板切换同步更新窗口标题，关闭再打开时保持当前面板。
- 面板内容从工具栏分隔线下方以紧凑、统一的页边距开始，不得因隐藏标签页容器的旧尺寸产生大块
  空白；四个面板的页标题顶距必须一致。
- “常用”：初始语言/简繁/全半角/标点，四码唯一、五码首选、自动调频，混输、编码提示、
  分号/单引号快捷选择和“显示扩展汉字”。
- “按键”：语言切换固定提供 Shift、Control、Caps Lock、禁用；简繁/全半角提供各自预设，
  以及五组独立翻页键、键盘布局和恢复默认。
- “外观”：以一个紧凑的“候选窗口”表单显示每页候选、排列方式和文字大小；每项必须有可见标题、
  当前值和简短说明，并提供随草稿更新的候选预览。不得出现无标签步进器或无意义复选框。
- 候选窗口使用有界的日常阅读字号、统一内边距、圆角和轻量边框；字号最大档仍须保持候选正文、
  序号和分页信息清晰，不把设置缩放值直接倍乘为巨大系统字体。
- 候选窗口必须实时响应系统“减少透明度”和“增强对比度”：普通状态可使用轻量系统材质，任一选项
  开启时切换为随深浅外观适配的实色系统背景；增强对比度同时使用更清晰的边框。
- 候选窗口保持非激活并跟随文本插入位置。纵向候选行填满内容区宽度，整行提供一致的悬停和点击区域；
  首选使用轻量强调底色与独立的前导形状标记，状态不得只由颜色表达。横向候选之间保留更宽间距。
- 多页页码以右对齐、等宽数字的紧凑页脚显示，并用分隔线与候选正文区分；单页不显示空页脚。空间不足
  时先隐藏编码提示，仍优先保留序号、首选状态与候选正文。

## Interaction

- 所有交互控件有稳定的产品内标识和普通键盘焦点顺序。
- 窗口始终区分已保存值和未保存 draft；Save、Cancel 和 Restore Default 均可纯键盘完成。
- Save 是非破坏性的默认操作并响应 Return；Cancel 响应 Escape。恢复默认和数据删除不得成为默认操作。
- Save 成功、失败和 future-schema 只读状态提供可见反馈；校验失败把键盘焦点移到第一个相关控件，
  同时保留其余 draft 便于修正。
- Restore Default 显示确认，明确说明只重置设置；取消不改变控件、快照或其他数据域。
- 外观控件改变时即时刷新页内预览和当前值；Cancel 必须同时恢复步进器、布局、字号、值标签和预览。
- 所有会写入 Settings 的控件在变化时立即更新 draft；无修改时 Save 与 Cancel 不可用并显示“所有更改均已
  保存”，存在修改时二者可用并显示“有未保存的修改”，不得等到保存时才暴露草稿状态。
- 外观页候选预览必须复用实际候选窗口的序号、首选强调、纵横布局与有界字号层级，不得退化为一块无
  选中状态的纯文本占位。

## Unsupported assistive technology

- 不发布 VoiceOver/屏幕阅读器专用 label、value、help、候选元素树、朗读公告或辅助焦点。
- 不承诺旁白实用工具、Accessibility Inspector、辅助选择或设置辅助导航。
- 系统开启辅助技术时仍必须保持一般故障安全，但这不是辅助技术验收通过的声明。

## Lifecycle

- 窗口打开/重新聚焦时读取协调器的最新已保存代次，不直接读写零散 UserDefaults。
- 成功保存后才刷新 saved baseline；持久化失败继续显示 draft 与错误，不假装设置已生效。
- 窗口关闭不隐式保存。
- 高级页必须把即时运行状态、用户词库管理和本地数据维护分为三个可辨识区域，危险操作不与普通
  开关混排。
