# Feature Specification: 设置体验增强

**Feature Branch**: `002-settings-experience` *(logical feature identifier; no Git branch hook configured)*

**Created**: 2026-08-02

**Status**: Implemented and automatically validated; final ordinary manual/distribution gates remain

**Input**: User description: "实现设置体验增强：可配置初始中英文、简繁体、全半角及中文模式标点；四码唯一自动上屏、五码首选上屏、自动调频；五笔拼音混输、编码提示、分号/单引号候选快捷键；可配置中英文和简繁切换键；支持逗号句号、减号等号、中括号、Tab/Shift-Tab、上下方向键翻页；全半角快捷键、键盘布局和恢复默认设置。所有设置需持久化、校验、即时或安全延迟生效，并提供自动化测试。"

**Scope Amendment**: 产品明确不支持 VoiceOver、旁白实用工具、Accessibility Inspector 或其他
屏幕阅读器专用候选朗读、辅助焦点与自定义辅助元素；删除已存在的专用适配，但保留普通鼠标、键盘、
候选显示、系统视觉偏好和设置错误反馈。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 配置常用初始状态 (Priority: P1)

用户可以在一个清晰的“常用”设置页中选择每个新输入会话的初始中英文、简繁体、
全半角和中文模式标点，并决定常用自动上屏与调频行为。设置保存后不需要重启输入法，
也不会破坏正在进行的组合输入。

**Why this priority**: 初始状态决定每次开始输入时的体验，是降低重复切换和误输入的最高频设置。

**Independent Test**: 修改所有初始状态，分别在空闲和正在组合时保存，然后创建新输入会话；
可独立验证新会话采用保存值、当前组合不被错误提交或取消、重启后设置仍存在。

**Acceptance Scenarios**:

1. **Given** 用户处于空闲状态，**When** 修改初始中英文、简繁体、全半角和标点并保存，
   **Then** 后续新会话立即使用完整的新初始状态。
2. **Given** 一个或多个会话正在组合，**When** 用户保存会改变输入语义的设置，
   **Then** 当前组合继续使用保存前的一致设置，组合安全结束后才切换到新设置。
3. **Given** 用户选择“中文下使用英文标点”，**When** 在中文模式输入标点，
   **Then** 标点按英文标点规则输出，同时保持中文候选输入能力。

### User Story 2 - 自定义高效按键 (Priority: P1)

用户可以选择中英文、简繁体和全半角切换键，同时独立启用多组候选翻页键。所有候选控制键
只在候选存在时生效，空闲时保持原有字符或应用快捷键行为。

**Why this priority**: 熟练输入用户高度依赖肌肉记忆；兼容常见键位可以显著降低迁移成本。

**Independent Test**: 启用每一种切换和翻页选项，在有候选、无候选、第一页、最后一页及
系统快捷键场景逐项操作；可独立验证映射、边界和透传结果。

**Acceptance Scenarios**:

1. **Given** 语言切换设为 Shift，**When** 用户在空闲状态单独按下并释放 Shift，
   **Then** 中英文状态切换一次；Shift 与其他键组合时不触发该切换。
2. **Given** 用户打开中英文切换选项，**When** 查看可选项，**Then** 必须依次提供 Shift、
   Control、Caps Lock 和禁用快捷键，且当前保存值清晰选中。
3. **Given** 多组翻页键同时启用，**When** 候选窗口可翻页，**Then** 任一已启用键组均按
   相同方向切页，未启用键组不控制候选。
4. **Given** 当前没有组合或候选，**When** 用户按逗号、句号、括号、Tab、方向键、分号或
   单引号，**Then** 输入法不把它们当作候选控制动作，并保留正常文本或应用行为。
5. **Given** 分号和单引号候选快捷键已启用，**When** 当前页存在第二或第三候选，
   **Then** 分号提交第二候选，单引号提交第三候选；目标位置为空时不得提交其他候选。
6. **Given** 用户查看系统输入菜单，**When** 当前绑定不是旧版组合键，**Then** 菜单不得显示
   写死或不可用的 `Control-Shift-1…4` 提示，也不得额外创建重复的状态栏项目。
7. **Given** 用户需要查看或改变私密模式与本地学习状态，**When** 打开“设置…”并进入高级页，
   **Then** 两项状态和控制均可在该页完成，菜单栏不得出现“`五·学`”或“`五·私`”独立项目。

### User Story 3 - 控制自动上屏与本地调频 (Priority: P1)

用户可以选择四码唯一候选自动上屏、输入第五码时提交当前首选，以及是否根据本地选择行为
调整同码候选顺序。每个选项独立工作，结果可预测且不会造成重复提交。

**Why this priority**: 自动上屏和调频直接影响五笔输入速度与准确性，错误行为会造成高成本误输入。

**Independent Test**: 对零候选、唯一候选、多候选、四码后继续输入及学习开关组合运行固定
输入序列；可独立验证每个事件最多提交一次、下一个编码不丢失、关闭调频后排序稳定。

**Acceptance Scenarios**:

1. **Given** 四码唯一自动上屏已开启，**When** 第四码查询恰好只有一个候选，
   **Then** 该候选立即提交；零候选或多候选不自动提交。
2. **Given** 第五码首选上屏已开启，**When** 四码组合后输入下一个有效编码字母，
   **Then** 当前首选最多提交一次，并以该字母开始下一段组合；当前无候选时不提交错误文本。
3. **Given** 自动调频已关闭或私密模式已开启，**When** 用户选择任意候选，
   **Then** 排序数据不写入且已有学习分数不参与排序。

### User Story 4 - 使用五笔拼音混输和编码提示 (Priority: P2)

不会某个字五笔编码时，用户可以直接输入连续全拼获得本地候选；熟悉五笔时仍能按原方式
输入。候选可显示简洁的五笔编码提示，帮助用户学习编码，不需要切换输入法或联网查询。

**Why this priority**: 混输降低生僻字和忘码时的中断，但不是熟练五笔输入的基础路径。

**Independent Test**: 使用同时可解释为五笔和拼音、仅有五笔结果、仅有拼音结果、重复文本、
长拼音及无结果序列；可独立验证候选来源顺序、去重、提示、选择和纯本地行为。

**Acceptance Scenarios**:

1. **Given** 五笔拼音混输已启用，**When** 用户输入有效连续全拼，**Then** 候选窗口显示匹配的
   简体或繁体候选，并遵循当前输出模式。
2. **Given** 同一输入同时产生五笔和拼音候选，**When** 展示结果，**Then** 五笔候选排在拼音
   候选之前，相同文本只出现一次，序号连续且可正常选择。
3. **Given** 编码提示已启用，**When** 候选具有已知五笔编码，**Then** 候选窗口显示该编码；
   关闭后正文、候选顺序和提交结果不变。
4. **Given** 混输已关闭，**When** 用户执行相同输入，**Then** 输入法只按五笔规则查询，行为与
   此功能加入前一致。

### User Story 5 - 安全保存、恢复和升级设置 (Priority: P2)

用户的设置在输入法重启、系统重启和升级后保留；无效或冲突设置会被明确拒绝。“恢复默认
设置”只恢复设置，不删除用户词库或学习数据，并允许用户取消操作。

**Why this priority**: 丰富设置只有在可靠持久化、迁移和恢复后才可用于日常输入。

**Independent Test**: 保存完整设置组合、重启、模拟升级、注入损坏或未来版本、制造按键冲突
并执行或取消恢复默认；可独立验证原子性、隔离性和数据保留。

**Acceptance Scenarios**:

1. **Given** 用户保存了一组合法设置，**When** 输入法或系统重启，**Then** 每个设置值保持一致。
2. **Given** 用户设置的快捷键冲突或值不受支持，**When** 尝试保存，**Then** 保存被拒绝，用户
   得到具体错误，最后一份有效设置继续生效。
3. **Given** 用户确认恢复默认，**When** 操作完成，**Then** 仅设置恢复为新安装默认值，用户词库
   和学习数据保持不变；取消时任何数据都不变化。
4. **Given** 已有用户升级到包含新设置的版本，**When** 首次加载，**Then** 旧设置语义被保留，
   新字段获得兼容默认值，迁移失败不覆盖旧快照。

### User Story 6 - 明确辅助技术支持边界 (Priority: P3)

用户在安装或查阅支持范围前可以明确知道产品不提供 VoiceOver、旁白实用工具、Accessibility
Inspector 或其他屏幕阅读器的专用候选朗读、辅助焦点和设置导航保证，不会被已删除或未经验证的
能力声明误导。普通鼠标和键盘输入仍保持不变。

**Why this priority**: 明确边界比保留无法稳定验收的辅助技术实现更诚实，也可减少候选焦点被系统
辅助层改变而影响日常输入的风险。

**Independent Test**: 检查产品说明和发布清单，再在不开启辅助技术的标准鼠标/键盘流程中完成
候选显示、翻页、选择和设置保存；同时验证产品中不存在专用朗读、辅助焦点或自定义辅助候选树。

**Acceptance Scenarios**:

1. **Given** 用户查看支持范围，**When** 查找辅助技术说明，**Then** 明确看到 VoiceOver、旁白实用
   工具、Accessibility Inspector 和屏幕阅读器专用功能不受支持。
2. **Given** 专用辅助技术适配已移除，**When** 用户用普通鼠标或键盘输入和配置，**Then** 候选显示、
   选择、翻页、保存、取消和错误反馈保持正常。
3. **Given** 系统已开启 VoiceOver 或其他辅助技术，**When** 输入法运行，**Then** 输入法不得崩溃或
   错误提交，但不保证候选朗读、辅助焦点、辅助选择或设置导航。

### Edge Cases

- Shift、Control 或 Caps Lock 作为语言切换键时，长按、按键重复、与其他键或修饰键组合不得
  造成多次或意外切换；Caps Lock 原有大写状态不得被意外破坏。
- 输入语义设置在多会话并发组合时保存，所有正在组合的会话必须各自完成旧快照，不能混用新旧值。
- 四码唯一自动上屏与第五码首选上屏同时启用时，一个候选不得被提交两次，第五码不得丢失。
- 四码查询为空或候选在输入第五码前发生变化时，不得提交过期候选或原始编码。
- 启用多组翻页键后，同一物理事件只能产生一个翻页动作；第一页向前和最后一页向后不得循环。
- Tab、Shift-Tab、方向键及标点键在候选关闭、设置关闭或应用快捷键带修饰键时必须正常透传。
- 分号或单引号对应的候选位置不存在时，候选与组合保持不变，不得降级选择第一项。
- 中文标点、英文标点与全半角组合必须有确定优先级，相同设置和输入始终产生相同结果。
- 连续拼音过长、包含非法字符、无法分词、没有候选或资源损坏时，必须有界失败并恢复，不得卡住输入。
- 五笔和拼音返回相同文本但编码、脚本或来源不同，界面必须去重且选择后只产生一次提交和学习增量。
- 编码提示过长、候选窗口空间不足或使用大字号时，正文和序号必须优先可见，提示可截断但不得遮挡。
- 选择当前系统不可用的键盘布局时，保存必须拒绝或安全回退到最后一个可用布局并明确告知用户。
- 保存过程中磁盘空间不足、进程终止或快照损坏时，重启必须恢复最后一份完整设置。
- 遇到未知未来设置版本时必须保留原数据且不得覆盖，只能使用安全默认状态并告知无法应用设置。
- 恢复默认不得关闭私密模式、删除用户词条、清除学习数据或改变其他独立数据域。
- 月度等价压力运行即使跨越逻辑日边界、重建会话或切换设置，也必须准确累计已提交正文；失败、
  取消和未提交组合不得计入 100 万字门禁，也不得为凑足计数而提交原始编码或错误候选。
- 系统开启 VoiceOver 或辅助检查工具时，输入法仍不得崩溃、卡住或错误提交；该安全行为不构成
  候选朗读、辅助焦点、辅助选择或设置导航支持承诺。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 产品必须提供清晰分组的常用与按键设置，使用户能查看当前值、修改、保存、取消
  和恢复默认，并且所有交互控件可通过普通鼠标或键盘操作。
- **FR-002**: 用户必须能分别配置新输入会话的初始语言为中文或英文、输出为简体或繁体、
  字符宽度为半角或全角、中文模式标点为中文标点或英文标点。
- **FR-003**: 标点和全半角组合必须采用确定规则：先按标点设置选择中文或英文标点，再对仍为
  ASCII 的可转换字符应用全半角设置；未命中转换规则的字符必须透传。
- **FR-004**: 初始状态只决定新会话或会话重新激活时的默认值；用户在会话内临时切换模式不得
  无意覆盖持久化默认值。
- **FR-005**: 产品必须提供“四码唯一时直接上屏”开关，仅当完整四码恰好存在一个有效候选时
  自动提交，并保证一次事件最多提交一次。
- **FR-006**: 产品必须提供“第五码将首选词上屏”开关；开启时，第五码事件必须先安全处理当前
  四码首选，再将第五码作为下一组合的第一个字符，且不得丢键、重复提交或提交空候选。
  开启五笔拼音混输且当前序列加入第五码后仍是有效连续全拼前缀时，必须优先继续拼音组合；
  只有当前输入已确定为五笔路径时才执行第五码首选上屏。
- **FR-007**: 产品必须提供“自动调频”开关，用于控制本地候选学习及学习分数是否参与排序；
  关闭、私密模式或禁止学习状态下不得产生学习写入。
- **FR-008**: 自动调频只能改变同码候选排序，必须有界、稳定、可清除，不得改变基础编码、
  词库正文或记录应用和文档上下文。
- **FR-009**: 产品必须提供可关闭的五笔拼音混输；开启时支持连续全拼候选，且所有拼音数据和
  查询完全位于本机，不依赖网络、账户或在线词库。
- **FR-010**: 混输结果必须保持五笔候选优先、拼音候选随后，并按最终显示文本去重；候选序号、
  翻页、选择、简繁转换和学习规则必须对合并结果一致生效。
- **FR-011**: 产品必须提供可关闭的编码提示；开启时，对具有已知五笔编码的候选显示简洁提示，
  关闭时不得改变候选正文、排序、选择或提交结果。
- **FR-012**: 编码提示必须遵循候选窗口的字号、布局、缩放和显示边界，空间不足时
  优先保留序号、选中状态和候选正文。
- **FR-013**: 产品必须提供可关闭的分号/单引号候选快捷键；仅在组合有效时，分号映射当前页
  第二候选、单引号映射第三候选，目标不存在时不得选择其他位置。
- **FR-014**: 用户必须能将中英文切换设置为 Shift、Control、Caps Lock 或禁用快捷键；前三种
  只在对应修饰键被单独按下并释放时切换一次，与其他键/修饰键组合、长按、重复或左右键交错时
  不得切换。默认值为 Shift。
- **FR-015**: 用户必须能将简繁体切换设置为禁用或文档化预设，预设至少包括
  Control-Shift-F；切换只改变输出脚本，不改变基础编码或默认设置。
- **FR-016**: 用户必须能将全半角切换设置为禁用或文档化预设；其快捷键不得覆盖系统保留组合，
  并只改变当前会话宽度状态。
- **FR-017**: 用户必须能独立启用或关闭以下候选翻页键组：逗号/句号、减号/等号、左/右中括号、
  Shift-Tab/Tab、上/下方向键；允许多组同时启用。
- **FR-018**: 每组翻页键必须使用前键向前、后键向后；仅在存在组合候选时消费，空闲、关闭、
  越界或带非预期修饰键时不得产生错误提交或破坏应用快捷键。
- **FR-019**: 产品必须提供键盘布局选择，至少支持跟随当前系统布局和美国布局；默认使用美国
  布局，所选布局不可用时必须拒绝保存或明确回退，不能静默改变按键含义。
- **FR-020**: 所有快捷键保存前必须验证空值、重复映射、相互冲突、系统保留组合和当前布局
  可用性；拒绝时必须指出冲突设置且保留最后一份有效配置。
- **FR-021**: 设置界面必须显示每个选项的当前已保存值；未保存编辑可以取消，保存成功或失败
  必须向用户提供明确反馈。
- **FR-022**: 候选外观等不改变输入语义的设置可以立即应用；默认模式、自动上屏、混输、学习和
  按键等语义设置必须以一致快照应用，在当前组合安全结束前不得中途改变该组合的行为。
- **FR-023**: 多个输入会话必须独立完成各自组合；设置切换不得造成会话串线、向错误客户端提交、
  重复提交、丢键或使用一半新一半旧的设置。
- **FR-024**: 所有设置必须作为独立版本化设置数据持久化，并在完整验证后原子替换；输入法重启、
  系统重启和正常升级后必须保留。
- **FR-025**: 从旧设置版本升级时必须保留已有用户选择的语义，新字段使用兼容默认值；未知未来
  版本、损坏或迁移失败必须保留原文件和上一份有效快照，不得破坏性降级。
- **FR-026**: “恢复默认设置”必须要求明确确认，只替换设置数据，不删除或回滚用户词库、学习
  数据和基础词库；取消操作不得产生任何写入。
- **FR-027**: 设置验证、保存、迁移、恢复和运行时应用失败不得崩溃、循环、错误提交或留下过期
  候选；必须恢复到最后一份有效设置或安全默认状态。
- **FR-028**: 设置、混输和调频不得建立网络连接，不得在生产日志、诊断或崩溃信息中记录按键、
  编码、拼音、候选正文、提交文本、应用身份或可重建输入时间线。
- **FR-029**: 新增设置不得改变产品仅支持 Apple Silicon arm64、无 Intel/Rosetta 支持、零重型
  运行时依赖和正式发行签名门禁。
- **FR-030**: 启用全部体验设置后，正常输入路径仍必须满足既有的首批候选可用时间和常驻内存
  预算；稳定性门禁必须执行代表 30 个逻辑输入日、累计至少 1,000,000 个已提交中文字符的确定性
  负载，并覆盖多会话、设置切换、五笔/拼音混输、调频和翻页。该门禁按实际完成的输入量验收，
  不要求连续运行一个自然月或固定八小时墙钟时间。
- **FR-031**: 每个设置及其组合必须有自动化覆盖，包括默认值、合法值、非法值、冲突、保存、取消、
  重启、迁移、中断、恢复、并发会话、按键透传和输入状态转换。
- **FR-032**: 产品必须明确声明不支持 VoiceOver、旁白实用工具、Accessibility Inspector 和其他
  屏幕阅读器专用功能；产品代码不得发布自定义辅助候选树、朗读公告或辅助焦点，不得以自动生成的
  控件语义暗示已通过这些工具验收。开启系统辅助技术时仍必须满足一般故障安全要求。
- **FR-033**: 系统输入菜单必须提供可点击的“设置…”入口；模式项只能显示当前真实生效的快捷键，
  禁用或没有键盘绑定的模式不得显示误导性快捷键。产品不得为重复显示模式状态而新增第二个
  常驻状态栏项目。
- **FR-034**: 私密模式和本地学习的当前状态与控制必须集中在设置窗口高级页；改变后必须立即应用
  到全部活动输入会话，并在重新打开高级页时显示当前运行状态。产品不得为这两项功能创建
  “`五·学`”“`五·私`”或其他独立常驻状态栏项目。

### Key Entities

- **设置快照**: 一次完整、已验证且版本化的用户设置集合，具有单调代次和上一有效版本，
  只能整体生效或整体失败。
- **默认输入状态**: 新会话开始时采用的语言、输出脚本、字符宽度和标点组合，不覆盖会话内临时状态。
- **自动上屏策略**: 四码唯一和第五码首选两个独立开关及其确定的提交、丢键防护规则。
- **候选学习策略**: 自动调频是否启用、已有分数是否参与排序及私密模式覆盖关系。
- **混输策略**: 是否允许本地连续全拼、五笔与拼音候选合并顺序、去重和提示显示规则。
- **按键绑定**: 模式切换、候选选择和多个翻页键组的启用状态、方向、布局及冲突验证结果。
- **设置应用状态**: 已保存设置、正在编辑值、各活跃会话使用的快照代次和待安全应用的代次。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在覆盖所有新设置及默认值的验收集中，100% 的单项修改和组合修改产生规格定义的
  输入结果，且每个输入事件最多提交一次。
- **SC-002**: 至少 90% 的目标五笔用户能在 3 分钟内完成初始状态、一个自动上屏选项和两组
  翻页键的配置，无需查阅开发文档。
- **SC-003**: 对全部切换键、五组翻页键和分号/单引号选择键的有候选、无候选及边界样本，
  100% 按配置执行或透传，系统和应用快捷键零误拦截。
- **SC-004**: 对四码零候选、唯一候选、多候选及第五码连续输入的完整组合矩阵，100% 无重复
  提交、错误提交或丢失下一编码。
- **SC-005**: 在固定五笔与全拼验收集中，100% 的预期混输候选可在不切换输入法的情况下找到，
  五笔优先和文本去重结果与预期完全一致，离线运行结果不变。
- **SC-006**: 保存设置后，输入法重启、系统重启和全部支持升级路径中的设置保留率为 100%；
  所有故意中断或损坏样本均恢复最后一份完整设置。
- **SC-007**: 保存语义设置时存在一个或多个活跃组合的压力验收中，100% 的组合使用单一一致
  设置快照结束，零会话串线、重复提交、丢键或过期候选。
- **SC-008**: 恢复默认的确认、取消和失败测试中，用户词库与学习数据的内容和代次 100% 不变。
- **SC-009**: 使用普通鼠标或键盘时，100% 的新增设置可被修改、验证、保存、取消和恢复默认，
  错误反馈包含受影响设置且键盘焦点保持可预测。
- **SC-010**: 启用全部新增设置的发布基准中，100% 的可识别输入仍在既有时间预算内显示首批
  候选，正常输入常驻内存保持在既有预算内；完成 30 个逻辑输入日且累计至少 1,000,000 个已
  提交中文字符后，首尾稳态窗口不存在持续内存或候选响应延迟增长，且所有会话提交计数准确。
- **SC-011**: 隐私审计检测到零网络连接，且设置、日志、诊断、崩溃产物和持久化数据中不存在
  原始输入历史、应用上下文或可重建输入时间线。
- **SC-012**: 自动化验收覆盖 100% 的功能需求，并至少包含一个成功路径、一个边界路径和一个
  失败恢复路径；所有既有输入、隐私、性能和发布契约测试继续通过。
- **SC-013**: 支持范围、用户指南和发布清单均明确标记 VoiceOver、旁白实用工具、Accessibility
  Inspector 和屏幕阅读器专用功能不受支持；产品源代码中自定义辅助候选树、朗读公告和辅助焦点
  实现数量为零，普通鼠标/键盘候选与设置回归全部通过。
- **SC-014**: 在 Shift、Control、Caps Lock 和禁用四种语言切换配置下，设置界面与系统输入菜单

## Assumptions

- 截图中的选中状态作为全新安装的默认配置；升级用户不会因为新增默认值而失去已有设置语义。
- “五笔拼音混输”指同一中文输入状态下接受连续全拼并与五笔候选合并，不包含云候选、模糊音、
  双拼、自定义拼音方案、语音输入或在线热词。
- 拼音候选来自随产品提供、可验证且可离线使用的本地资源；其许可、来源、规范化和更新证据
  必须达到基础五笔词库相同的隐私与可复现要求。
- 编码提示指在候选旁显示已知五笔编码，主要用于拼音找字后的五笔学习，不记录用户查询历史。
- 中英文 Shift、Control 或 Caps Lock 切换只在对应键单独按下并释放且没有按键重复时触发；
  组合输入存在时沿用既有安全取消策略，再切换当前会话模式，不提交原始编码或候选。
- 修饰键切换只能处理活动输入会话实际交付的事件，不安装全局键盘监听，不在输入法未激活时
  观察按键；若受支持 macOS 无法交付所需事件，该平台验收必须失败并回到范围决策。
- 多组翻页键可同时启用；每组左侧或前一个键向前翻页，右侧或后一个键向后翻页。
- 键盘布局第一阶段至少提供“跟随系统”和“美国”两个选择；更多布局不是本功能完成条件。
- 当前候选数量、布局、字号、用户词库、隐私与导入导出功能继续存在，但不在本功能中重新设计。
- 本功能依赖现有的会话隔离、候选窗口、设置快照、学习、简繁转换、发布验证和隐私审计能力。
- 产品仍仅支持 Apple Silicon arm64 和 macOS 13 或更高版本；Intel Mac、Rosetta 2、联网服务、
  App Sandbox 和 Mac App Store 分发不在范围内。
- 产品不阻止用户启用系统 VoiceOver 或其他辅助技术，但不为它们实现或保证专用候选朗读、辅助
  焦点、辅助选择和设置导航；“不支持”不允许成为崩溃、卡住或错误提交的豁免。
- “一个月的连续输入强度”按 30 个逻辑输入日和累计至少 1,000,000 个已提交中文字符定义，
  是可重复的工作量门禁而不是持续 30 天的墙钟测试；每个逻辑日必须包含会话结束与重新建立，
  整体负载必须保持确定性且不得使用真实用户输入。
