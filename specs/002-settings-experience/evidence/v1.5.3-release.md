The macOS administrator authorization completed and `Scripts/upgrade.sh` atomically replaced the system bundle.

```sh

xcrun swift Scripts/select-input-source.swift

```

Installed version readback is 1.5.3 (15), strict verification passed, and the executable matches the verified
build byte for byte. The system reports exactly one MacWubi input source and selects
`org.macwubi.inputmethod.MacWubi`. The installed process started successfully and its point-in-time network
connection audit passed. Installation preserved personalization data.

Automated TextEdit keystroke injection could not run because macOS denied `osascript` Accessibility permission.
After the installed input-method process was terminated, the bundle re-registered, the source reselected and

a candidate. Fifth-code preservation and the normal `wqvb` regression remain covered by the passing engine and
adapter test suites.

## Constitution and remaining gates

No architecture, dependency, InputMethodKit boundary, recovery, persistence, or privacy contract changed. The
package is thin arm64, Apple Development signed, hardened, has empty entitlements and uses only system libraries.
The new direct-input fallback is excluded from learning writes.

This source release does not claim Developer ID, notarization, staple, public Gatekeeper, or the macOS 13/current
cross-application release matrix. The canonical test script's short stress scenario is not a fresh full
million-character monthly run, and no new normal-input memory measurement is claimed.
