## Installation

The macOS administrator authorization completed and `Scripts/upgrade.sh` atomically replaced the system bundle.

```sh
Scripts/upgrade.sh /Users/agol/repos/wb86/.build/xcode/Build/Products/Release/MacWubi.app
Scripts/verify-release.sh '/Library/Input Methods/MacWubi.app'
plutil -extract CFBundleShortVersionString raw -o - '/Library/Input Methods/MacWubi.app/Contents/Info.plist'
plutil -extract CFBundleVersion raw -o - '/Library/Input Methods/MacWubi.app/Contents/Info.plist'
cmp .build/xcode/Build/Products/Release/MacWubi.app/Contents/MacOS/MacWubi '/Library/Input Methods/MacWubi.app/Contents/MacOS/MacWubi'
xcrun swift Scripts/select-input-source.swift
```

Installed version readback is 1.5.2 (14), strict verification passed, and the executable matches the verified
build byte for byte. The old installed process was terminated and the new installed bundle started successfully.
The system reports exactly one MacWubi input source and selects `org.macwubi.inputmethod.MacWubi`.
Post-restart `Scripts/privacy-audit.sh` with the installed process ID passed, including a point-in-time
network connection check. Installation only replaces the application bundle; it does not migrate or delete personalization.
