# v1.5.4 release evidence

Date: 2026-09-11. Tasks: feature 002 T114 (raw-input preservation and Return commit), T115
(candidate-panel placement), T116 (package/install/source release).

## Scope and environment

- MacBook Air (Mac15,12), Apple M3, 24 GB, native arm64, macOS 26.6.2 (25G83), Xcode 26.6 (17F113).
- Bundle: MacWubi 1.5.4 (16), macOS 13.0 deployment target.
- An unmatched raw candidate keeps accepting later letters as one composition until Space, Return or explicit
  selection. Return commits the full raw sequence without a newline or learning write, and mixed Pinyin preserves
  `zz` when the second letter removes the viable Pinyin route.
- Candidate placement uses the complete InputMethodKit line-height rectangle. It keeps a 4-point gap below the
  marked-text line or flips above the line when the lower screen edge has insufficient room.

## Constitution and remaining gates

The product remains pure Swift, thin arm64, macOS 13+, dependency-free and offline. Core still has no AppKit or
InputMethodKit import; the full line rectangle is obtained and translated only at the InputMethodKit adapter
boundary. Direct raw fallback and Return commits remain excluded from learning writes. Recovery and persisted-data
formats did not change.

This source release does not claim Developer ID, notarization, staple, public Gatekeeper, or the macOS 13/current
cross-application release matrix. The canonical test script's short stress scenario is not a fresh full
million-character monthly run, and no new normal-input memory measurement is claimed.
