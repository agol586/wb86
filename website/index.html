隐私不是设置项，是架构

输入不需要经过互联网。

Mac Wubi 86 没有网络 entitlement，不创建网络连接，也不记录按键、候选、提交文本、应用身份或可重建输入过程的时间线。

常见问题

开始之前，先说清楚。

可以直接下载安装吗？＋

v1.5.2 Release 提供源码归档。Developer ID 公证与 Gatekeeper 最终证据仍在完成，因此目前仍需使用 Xcode 构建并签名。

忘记五笔编码时怎么办？＋

默认开启五笔拼音混输。直接输入全拼即可继续找字，五笔候选仍然排在前面；也可以在设置中关闭混输。

输入内容会上传吗？＋

不会。产品不具备网络客户端或服务端 entitlement，候选查询、学习和用户词库全部在本机完成。

支持哪些 Mac？＋

支持 Apple Silicon 与 macOS 13 或更高版本。Intel Mac、Rosetta、五笔 98/新世纪、双拼和云候选不在支持范围。
